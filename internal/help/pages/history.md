# Past conversations

[[key:history]], or **History** in the rail, lists the conversations stored
for this project and resumes any of them into a new tab.

For each one it shows the opening prompt, how long ago it was touched, how many
entries it holds and its session id. **Resume** opens it in a new tab and picks
it up where it stopped.

This covers the conversations no pane is currently attached to: the one from
yesterday, or one whose pane you closed. A conversation that *is* open in a
pane is shown as such rather than offered twice, because two panes on one
transcript would fight.

The list is read from Claude Code's own transcripts rather than from anything
Flockdeck keeps, so Claude Code conversations from sessions that had nothing to
do with this application are in it too, and a conversation resumed from it
opens as a Claude Code pane. Conversations with other agents, the built-in
chat client included, are not listed.
