# Flockdeck v0.3.30

## Jump straight to another dialog
Projects, Agents, Worktrees, Settings and the rest each open their own
dialog, with no way to reach one from inside another. Every dialog now
has a "Go to…" next to its "?", opening the command palette narrowed to
just the actions that switch pages.

## Agents and API keys, in the rail
The side panel already opened everything else with one click. It now
does the same for the all-agents overview and for API keys, the two
dialogs that were reachable only from the keyboard or the palette.

## No more flickering tips
Dismissing a tip — or bringing them all back from Settings — could
flash back to how it was a moment before, if a background update to
your preferences arrived while the change was still in flight. It no
longer does.

## Reviewing a grouped project's other repos
Changes reviewed one repo's working tree at a time, with no way to
reach another one in a project spanning several — reviewing the second
meant closing the dialog and switching projects first. It now offers
every repo in the group right there.
