# Flockdeck v0.6.0

This release adds agent roles, messages between agent panes and a shared task board. It also fixes a removed project that came back with its old position and name.

## Roles

A role is a job an agent is started for. Flockdeck has six: `manager`, `planner`, `worker`, `reviewer`, `tester` and `docs`. Start an agent in one with `flockdeck spawn -role <id>`, for example `flockdeck spawn -role reviewer "review the token refresh change on fix-auth"`.

- `flockdeck agents` lists the roles after the agents.
- An agent in a role gets a "Your role" section in its briefing, and its environment has `FLOCKDECK_ROLE`. The role is saved with the layout.
- A role lists the roles it may start under `spawns`. The `manager` role may start the others.
- Add your own roles, or change a built-in one, under a `roles` key in `agents.json`. A role can name an agent, a model or a tier (`small`, `mid` or `top`), a briefing and a worktree policy.

## Team and messages

An agent's briefing has a "Your team" section listing the other agent panes in its project, with role, name, agent, model and status. `flockdeck team` prints the live list, and `-json` prints it as JSON.

- `flockdeck msg send <target> <text...>` sends a message to a pane id, a peer name, a pane name or a role id. A role id reaches every live pane in that role.
- `flockdeck inbox` lists an agent's messages, and `flockdeck inbox read <id>` shows one.
- When an agent is idle, Flockdeck types a one-line notice into its pane saying a message has arrived.
- When a helper started with `spawn` finishes, its parent gets a message.

## Task board

Each project has a task board that its agent panes share, whatever worktree they work in. Agents use `flockdeck task` with `add`, `list`, `show`, `assign`, `status`, `note`, `branch`, `baton` and `prune`.

- A task has a title, a body, an owner, a branch, a thread of notes and a state: planned, assigned, in-progress, in-review, done, blocked or cancelled.
- Roles decide who may move a task. Only the manager assigns tasks, and a task in review is closed by the manager, a reviewer or a tester.
- Agents are messaged when a task is assigned, noted, moved to review, blocked, done or cancelled.
- `flockdeck task prune` removes done and cancelled tasks older than 30 days, or older than `-days N`.

## Fixes

- A project you removed and opened again came back in its old position with its old name until you restarted Flockdeck. It now comes back with its current order and name.
- A role that may not start agents, such as `worker` or `reviewer`, no longer gets a briefing section telling it to run `flockdeck spawn`.
- A message notice names the sender's role and name, and `inbox` shows the sender's pane id.
- A refused task move now says why.
