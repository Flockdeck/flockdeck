- A structured pane starts helpers with the `spawn` tool. It takes the same role, name, tab, worktree and agent options as `flockdeck spawn` and is checked by the same rules.
- A paired phone that supports it can now read and, where you allow it, control Flockdeck over an end-to-end encrypted connection the relay cannot read. It can read conversations, diffs, changes, the team view and GitHub. With the new per-device Control agents switch (Settings, Remote, off by default) it can also send messages, stop a turn, answer a question, approve a plan, start agents and change push settings. Commit, push, pull and GitHub comments run only after you say yes in the Flockdeck window on this machine. Merges, keys, pairing and updates stay at the desk. See docs/remote.md.
