# Flockdeck v0.3.37

## A stuck pane on Remote now says why, instead of spinning forever
A pane opened through Remote's per-desktop full interface, on a device with
a registered end-to-end key, could get stuck reconnecting its terminal at
full speed forever, with nothing ever appearing in the pane. The interface
has no client-side WebCrypto of its own yet to complete that handshake, and
the reconnect logic couldn't tell a handshake refusal apart from an
ordinary dropped connection, so it kept retrying at top speed instead of
backing off. It now recognizes this specific, unrecoverable refusal, stops
retrying, and covers the terminal with an explanation and a Try again
button. The handshake itself isn't fixed yet — that's a bigger piece,
tracked separately — but the storm and the silent blank pane are gone.

## Linux gets an app-menu entry; Windows gets a real installer
Installing Flockdeck on Linux now adds it to your app menu and launcher
search, with its own icon — not just a binary you have to know the name of.
Windows now also gets a proper installer (Start menu shortcut, desktop
shortcut, a real uninstaller) alongside the existing zip, for anyone who'd
rather run an installer than unzip a folder by hand.

## Multi-directory projects: worktrees, new tabs and terminology catch up
A project spanning more than one directory already worked for most things;
a few features hadn't caught up. "New worktree" now offers a repo picker
for a multi-member project, existing worktree rows say which repo they
belong to, and free branches are correctly grouped by repo instead of
merged into one list. The project switcher's member rows get their own
Agent/Shell buttons, to open a tab directly in a specific directory. Switcher
copy now says "directories" rather than "repos" where a project mixes git
and non-git members.

## A denied tool call is now reported as blocked, not idle
An agent whose tool call was refused outright by a permission or safety
check, and which then stopped on that turn, looked exactly like a pane that
had simply finished its work — nothing marked it as needing attention. It
now shows the same amber "needs attention" treatment as a pane waiting on
an approval, with its own explanation, so a stuck pane doesn't go unnoticed
until someone happens to check it by hand.
