# Flockdeck v0.3.39

## A pane no longer garbles for everyone already watching it when a new viewer joins
Opening a pane's terminal from a new device — most visibly, Remote's full
interface on a phone or another browser — forced a resize-and-restore on
that pane to make a stuck full-screen program repaint for the new viewer.
That resize landed on every other window already watching the same pane
too, glitching their terminal for a moment for a repaint nobody there
needed. The forced repaint now only fires when the new viewer is the only
one watching.

## flockdeck remote enable can wait for a verified email
The shared relay can now require proof of a real inbox before
`flockdeck remote enable` creates an account and starts a trial, closing a
free-trial-abuse hole. Off by default, and only relevant to the shared,
hosted relay — a self-hosted or company relay already gates registration
its own way and has no free trial to abuse.

## A pane can close another pane
`flockdeck close` lets a pane end another pane's session programmatically,
rather than needing a person at the keyboard to do it.

## Hovering a pane's header shows its full task
Long task descriptions used to be cut off in a pane's header with nowhere
to read the rest. Hovering it now shows the whole thing.

## Real macOS and Linux packages
Flockdeck now ships as a real, ad-hoc-signed `.app` bundle on macOS, and as
real `.deb` and `.rpm` packages on Linux, instead of a tarball on either.
