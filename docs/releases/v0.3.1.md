# Flockdeck v0.3.1

A reliability-focused release: keyboard focus, agent connections and routing, remote access and layout persistence all get a round of fixes.

## Keyboard focus stays where you left it
A long run of fixes so that actions no longer send keyboard focus somewhere unexpected. F2 renames the tab the keyboard is on, and Ctrl+Enter in the commit message box commits once instead of repeating. Escape in an API key field now closes just the field, not the whole dialog. Focus is kept in place through reconnects, through a review or conversations list redrawing under you, and when a row's figures move or a control it was on gets disabled - including in the remote access dialog and the routing rules view.

## Agents, keys and routing
- Key stores and settings files saved with a byte-order mark (common from some Windows editors) are read correctly again, and keys saved at the same moment are no longer dropped.
- Routing rules: a rule's kind now matches whatever case it's written in, file globs match whether you write them with backslashes or `./`, and a rule naming an agent you don't have configured says so instead of silently doing nothing.
- An endpoint written as `LocalHost` now connects without asking for a key.
- Talking to OpenAI or Gemini directly through the chat client, your running cost now includes prompt tokens served from cache and is labelled as an estimate; a thinking model's reasoning time now reaches the pane header's figures too.

## Remote access
Moving to a different relay now tells you to run enable again with the relay's name and fresh join and invite codes, rather than leaving you to guess. A relay address given as `ws://` is refused, the same as `http://` - remote access always requires an encrypted connection. The pairing link in the remote access dialog can now be copied with a button, and renaming an enrolled machine quotes the new name correctly when it needs to.

## Workspaces, layouts and worktrees
- Layouts now autosave roughly every 30 seconds while Flockdeck is running, and closing a project says if its layout couldn't be saved.
- A restored pane reopens at the size it was last drawn, and never smaller than the default.
- A pane whose folder has disappeared says so, and what to do about it; the same goes for a worktree that git refuses to create - you now see git's own explanation instead of a generic failure.
- A fan-out step whose description ends in a colon no longer loses the detail that follows it.

## Self-update
Two updates downloading at once no longer collide over the same temporary files. A slow download is left to finish; only one that's actually stalled is given up on. Update signatures are now checked strictly against what dl.flockdeck.ai supplies, and on startup Flockdeck can find files an update moved aside even when the move went through a symlink.

## Also in this release
`install.sh` and `install.ps1` handle a trailing slash on the install path and a machine with neither curl nor wget more gracefully. The folder browser explains itself when a path names a file, a missing folder, or a bare drive letter. Agent tools such as grep and glob now handle UTF-16 and byte-order-marked files correctly, including ones with an unpaired surrogate. Vivaldi is now recognised as a browser on Windows and macOS. A large number of smaller fixes and polish landed alongside these.
