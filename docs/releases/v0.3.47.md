# Flockdeck v0.3.47

## Auto-review: two more ways past it are closed
**If you turned auto-review on, update.** Auto-review is still **off by
default**, and this release does not change that; it only covers Claude Code
panes. Two more things it approved without asking are now asked about:

- **A very long command.** Flockdeck looks at the first 64 KiB of a command
  when it decides, but Claude Code runs the whole command. A command that
  began with harmless text and carried a `;` and a second command past that
  point was approved on the strength of its beginning. Auto-review now asks
  about any command over 4 KiB, so a command is never judged by a prefix.
- **A read of a secret file.** `cat .env`, `cat id_rsa` or `grep token
  aws-credentials` read a file inside the project and put its contents in the
  transcript, which goes to your model provider, with no prompt. Auto-review
  now asks about any command that names `.env` or `.env.*`, a private key
  (`id_*` but not `id_rsa.pub`, `*.pem`, `*.key`, `*.p12`, `*.pfx`, `*.ppk`,
  `*.keystore`, `*.jks`), `.npmrc`, `.netrc`, `_netrc`, `.pgpass`,
  `.git-credentials`, or any name containing `credential`.

A command that stops now reaches the ordinary permission prompt, as it would
with auto-review off.

**Not changed, and now written down:** these checks read the command as text,
not the filesystem. A symlink inside the project that points outside it is
followed; the secret-file check knows only conventional names, so a recursive
`grep -r` or an oddly named secret is not covered. Auto-review is not a
sandbox. The README and the in-app help now say so, and that this is part of
why it is off by default and only worth turning on for an agent you trust.

## Lock a pane so it cannot be closed
Each pane has a **lock**, a padlock in its header and a "Lock pane" /
"Unlock pane" entry in the command palette. A locked pane shows "Locked" in
its header, and while it is locked every way of closing it refuses:

- Ctrl+Shift+W and the header close button (a click says the pane is locked);
- closing a tab or project that contains a locked pane;
- Close finished panes, which skips locked panes and says how many it left;
- `flockdeck close <id>`, which errors; `flockdeck close --finished` skips
  locked panes and reports the count.

**`--force` does not override a lock.** `--force` means "close even though it
is still working"; a lock is your own guard against exactly the agents that
would pass it, so only you can undo it. The lock is saved with the layout,
moves with the pane to another tab and survives Restart pane.

## Record a pane's session (off by default)
A **Record** button in a pane's header, and Start recording / Stop recording /
Open recordings folder in the command palette, write the agent's session to a
file as one JSON object per line: your prompts, the assistant's last message
of each turn, tool calls and results, permission prompts and their outcome,
and status changes. **It is off for every pane** until you turn it on, and
the first time it asks you to confirm. `flockdeck spawn --record` is refused
until you have confirmed in the window, so an agent cannot be the first to
switch it on.

- Files go under Flockdeck's state directory, in `recordings/<project>/`, one
  per session, never into the repository. A file stops at 16 MiB; a project's
  folder keeps 30 days, 100 files and 256 MiB.
- `flockdeck recordings` lists them (`-dir` prints the folder, `-json`).
- The format is documented in `docs/recording-format.md`, with a JSON Schema.
- **Redaction is best effort, not a guarantee.** Private keys, common token
  shapes, URL credentials, values with secret-looking names and the output of
  secret files are replaced, and long fields are clipped and marked. It does
  not catch a secret under an unconventional name (`SESSION_COOKIE`,
  `DATABASE_URL`), an encoded or split one, or a secret read through a symlink
  or an ordinary file name. On Windows a recording is readable by you and a
  local administrator: it is saved on your machine, not private to you.
- **Gaps:** only the last assistant message of each turn is available;
  permission outcomes are inferred; Codex, Gemini CLI, Aider, opencode and
  Cursor Agent report no events, so their recordings hold only the start and
  the stop; the built-in chat records tool names only.
- Fixed before release: a quoted secret value containing the letter `n` was
  not redacted.

## Pop-over redesign: the screens
The overlay system in v0.3.46 changed how screens open; this release changes
what is inside five of them.

- **Command palette.** With nothing typed, commands sit under headings
  (Recent, then Panes, Tabs, Agents, Go to and so on). Rows use short names
  (Agents, Changes, History, Remote, API keys; the full name is still
  searched), keys are drawn as key caps, and a footer counts the commands and
  lists the keys. A typed search stays one flat list, with commands whose name
  starts with what you typed first. **Go to** is a mode: choose it, or type
  `>` first, and Backspace in the empty field leaves it. An empty result says
  what to try.
- **Worktrees.** Each row has one action, Open agent, and a **⋯** menu (Open
  shell, Split beside this pane, Review changes, Remove worktree…). Creating a
  worktree is the form at the foot of the sheet. Removing a worktree with
  uncommitted work still asks first.
- **Settings.** Eleven sections in four groups: Window (General, Appearance,
  Terminal, Keyboard), Agents (Agents & models, Routing, API keys, Status
  detection), Connections (Remote access, GitHub) and Account (Account &
  plan). **Find a setting** is in the header. The version controls
  (auto-update, Check for updates, Install a specific version) moved to
  Account & plan. The settings themselves are the same.
- **Fan out** is one editable task list: a field and a model for each task,
  "Add a task…", Edit as text for pasting a list, a model for every task, a
  Where they run group, and a footer with a summary and **Start N agents**
  (Ctrl+Enter). If the pane's screen ends in a permission prompt, fan out says
  it looks like a question, not a plan, instead of offering the prompt's
  options as tasks. At 600px wide a row's model name is still cut off.
- **Notices** stack up to three at a time, an error has a lead-in and a ×, and
  a notice can carry a button. The server's notices now start with a capital
  letter.

**Not changed:** what the commands do, and the keys. Screens not listed here
(Agents, History, Todos, GitHub, API keys, Remote access, Projects) are as in
v0.3.46.

## Wording and small fixes
- A Settings row's label and description no longer wrap a word per line when a
  menu sits beside them; the control drops under the words when they do not
  fit.
- Corrections to in-app, command-line and agent-briefing text: a blocked pane
  is described as blocked, not as exited or killed; turning remote access off
  says that turning it on again enrols afresh; pairing says it covers every
  agent on every machine on the account, and a shell; the "Coming soon" note
  names Enterprise; the sign-out confirmation says it runs `gh auth logout`
  for the whole machine; the grouping tooltips say agents are told about the
  other directories, not that they can see them; "Flockdeck" is capitalised in
  window titles and prose.
- Tests no longer read your real config folder or stored keys, or make real
  network calls. This changes nothing in the app.

Update if you have auto-review on; otherwise nothing needs doing.
