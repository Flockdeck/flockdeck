# Flockdeck v0.3.40

## Optional: TypeSafe's Jev can help read a quiet pane's status
For an agent that reports no status of its own, a pane that goes quiet is
either finished or stopped on a question, and the bell and the quiet timer
look the same for both. With **Settings › Behaviour › Status detection** on
and a `TYPESAFE_API_KEY` in the environment Flockdeck runs in, TypeSafe's
Jev model is asked which it is, and a confident "waiting" or "blocked"
answer turns the pane's idle into that. Off by default, and it needs both:
turning it on sends the last 30 lines of that pane's terminal output, at
most 2,000 characters, to TypeSafe, a third party, and secrets on screen
are not removed, so it is a choice made on the machine itself and cannot be
switched on from a window reached through the relay. Panes of agents that
report their own status, and shells, are never sent. It only ever moves a
pane from idle to waiting or blocked, never the other way, and any failure
leaves the status as it would have been.

## Optional: Jev can size a fan-out row for cost-first routing
Under **Minimise cost**, a fan-out row that no routing rule matches used to
go to the cheapest model in the floor tier whatever the task was. With
**Settings › Agents › Routing › Ask Jev to rate unmatched work** on (and the same key), the row's task
text is sent to TypeSafe to rate how demanding it is, and the row is given a
tier to suit: never below your floor, never above the model it would have
run on anyway, never on another agent. Off by default; the settings text
says what is sent. Routing decisions that fell back are now recorded, and
Settings shows how often plain and Jev-assisted ones get overridden, so
you can see whether it is choosing well.

## Windows and Linux downloads
The download page now offers the Windows installer (one file for x64 and
Arm) and the Linux `.deb` and `.rpm` packages beside the archives, and they
are served with the right content types. The Linux packages are installed
in clean Debian-family and Fedora containers on every change to how they
are built, on both architectures; that found and fixed the `.rpm` leaving an
empty `/usr/share/doc/flockdeck` behind after `rpm -e`.

## Small fixes
Closing a pane now also forgets its remote-use and inbox-preview records,
which used to be kept for as long as Flockdeck ran, and two windows opening
the same fresh full-screen pane at once can no longer both skip its
repaint. Help now explains that Remote's dialog cannot wait on a relay's
email verification (use `flockdeck remote enable` from a terminal) and that
a project grouping several folders picks which repository the review and
worktree panels use.
