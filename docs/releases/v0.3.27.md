# Flockdeck v0.3.27

## Grouping repos into one project
A project can now actually be grouped from the app itself: "Group open
projects…" in the Projects dialog ticks two or more open projects and
merges them into one, named however you like. A grouped project's row
expands to show every repo inside it — jump to one directly, or split it
back out on its own — and "Add repo…" adds another into an existing
project without leaving the dialog.

## A withdrawn version now says so
If the version you're running gets pulled after release, Flockdeck already
knew and said nothing about it. A banner now shows why, above the usual
tips, with a button to check for or install the fix — not just a quiet
chip you'd have to notice on your own.
