# Flockdeck v0.3.6

Push notifications to your phone are now based on whether you've actually stepped away from your desk, rather than simply whether the Flockdeck window has focus - so you're less likely to be pinged while you're still sat at the keyboard in another app, and less likely to be missed while you've drifted off with the window still focused.

Headless Linux installs can now receive push notifications too, and Flockdeck only asks the OS about desk activity when the answer could actually change the outcome, keeping the check cheap.

The push notifications and remote-access documentation has been refreshed to match, and a few stale claims about remote access were corrected.
