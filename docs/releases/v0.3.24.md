# Flockdeck v0.3.24

## Auto-review for permission prompts
Agents can now auto-review their own permission prompts, similar to Codex - only ever letting through requests that genuinely just read, never anything that writes or changes state. There's no setting to control this yet.

## Icons
The app and taskbar icon are sharp at every size and state, and the website's favicon and touch icon have had the same treatment.

## Fixes
Clicking a tab now reliably switches to it, even if the pointer drifts slightly during the click.
