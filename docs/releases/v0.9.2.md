# Flockdeck v0.9.2

This release lets you list and remove "always allow" grants from a structured pane, keeps a file-overlap item quiet once the manager has been asked, and adds three task commands to the CLI help.

## Always-allow grants

When you choose "Always allow" on a permission card in a structured pane, the agent adapter keeps the grant for the session. Until now there was no way to see those grants or take one back. The Agent info panel now lists them, each with a Remove button.

- This works for Claude Code and Codex structured panes.
- A rule's text is redacted and then cut to 300 bytes. A Claude rule also shows whether it applies with the sandbox off, in the background, or with a timeout, so two variants of one command read differently. A list of more than 200 rules is cut.
- The commands are for the desktop only. A viewer or a relay window is refused.
- The control socket API is at version 1.29.

A grant still lasts for the session only, and the agent asks again after a pane restarts.

## File overlaps

When two workers change the same files, the team view shows a "Files overlap" item with a button to ask the manager. Before, the item stayed at full "needs you" priority after you had asked, and the "Manager asked" state was lost on a redraw, so the same prompt could go out twice.

- The ask is saved for each pair of overlapping workers, in the window's local storage. It survives a redraw, a remount and a reload.
- Once asked, the item leaves the needs-you strip and the team counts. The block shows "Manager asked, waiting on the workers", and the pane row shows "waiting on the workers: overlaps <name>".
- "Ask again" sends the prompt a second time.
- If the overlap grows to a file that was not there when you asked, the item returns to full priority.

The per-pane and per-team "needs you" counts that the server reports still include the overlap. The window cannot change those.

## CLI help

`flockdeck -h` and the `cli` help page listed the task commands as add, list, show, assign, status, note, branch, baton and prune. They now also list `depends`, `estimate` and `team`. The commands already worked; only the summaries were missing them.

## What was and was not tested

The Go tests for the adapters and the rules commands passed under the race detector. One test in `internal/structured` times out under the race detector on a clean main as well, and the whole `internal/server` package was not run to the end. The Always-allow list and Remove were not tried against a real Claude Code or Codex session.
