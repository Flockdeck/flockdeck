# Flockdeck v0.3.5

## Notifications on paired devices
When a pane has been waiting on you for a while, Flockdeck can now push a notification to your paired devices, so you don't have to keep checking back. Notifications are end-to-end encrypted before they leave your desktop - the relay only ever handles the encrypted payload - and Flockdeck won't notify a device you're already using, or send anything while you're active at the desktop itself. At most one push goes out a minute.

## Remote access reliability and security
- Flockdeck now says plainly when this machine is no longer paired, and why.
- A device that stays offline for 30 days is removed from your paired list.
- A window opened through the relay now refuses to be embedded by another site.
- The one-time link used to open a paired window no longer appears on the browser's command line.
- A failed app launch no longer leaves a stray redirect file behind.
- Self-update now also accepts releases signed with Flockdeck's standby signing key.
