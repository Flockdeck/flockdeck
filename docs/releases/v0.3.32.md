# Flockdeck v0.3.32

## A tighter install script
`install.sh`'s `mkdir -p` left the install directory exactly as your
umask set it — group- or world-writable under a looser umask (0002, or
0000 in some containers), which let another local user swap out a
binary that updates and runs itself with your privileges. Pinned
explicitly now, matching the binary's own permissions two lines below.

## A hint that stopped flickering away
Several of the header's hints only show for a particular pane status,
which flips on every tool call a busy agent makes. Dismissing one
could let a different hint take its slot, only for that flip to show
it and immediately take it away again on the very next update. A
hint's slot now has to agree for a moment before anything changes it.

## Self-hosted Docker image builds again
The self-hosted image's `CGO_ENABLED=0` build broke compiling code
Wails' Linux GUI backend needs cgo for — code the image doesn't even
use, since `-no-window` and `-detach` never open a window. Split
behind a build tag, so the Docker build compiles clean again on both
its target platforms.

## Shift+Enter in a terminal inserts a line, not submits
Typed straight through, a terminal can't tell "Enter" from "Enter
held with Shift" — both were one `\r`, submitting early in any CLI
that expects Shift+Enter to insert a line instead. Now sent as a
paste, the same trick Flockdeck's own prompt bar already uses for
exactly this.
