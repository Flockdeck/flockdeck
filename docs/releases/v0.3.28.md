# Flockdeck v0.3.28

## A tidier widened sidebar
Widening the rail into a labelled panel drew every row's icon at its own
width, so a project's two-letter tile sat 8px further right than a tool's
icon below it, and the Remote status dot landed on top of the "R" in its
own label. Every row's icon now sits in the same 24px column as a
monogram tile, so labels line up and the badge clears the text.
