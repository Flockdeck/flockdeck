# Flockdeck v0.2.3

## Remote access: reach Flockdeck from another device

Flockdeck can now be paired with another device — a phone or a second computer — through a relay, so you can check on or drive your agents without opening a port on your own machine.

- Pair a device by scanning a QR code or typing a short pairing code, then see it listed, and revoke it individually, from the window.
- Remote access can be turned on and off from the window itself, not only from the command line.
- Traffic to a remote device is now compressed and a pane's history is sent in smaller frames, so a slow connection still keeps up; a dropped connection picks back up rather than restarting the session.
- Flockdeck checks that a relay's certificate is genuinely trusted, and explains in plain words when a relay can't be reached or has closed the connection, instead of showing a raw network error.

## A built-in chat client for API agents

When a pane talks to a model API directly — Anthropic, OpenAI, Gemini, or an OpenAI-compatible endpoint — Flockdeck now drives it with its own chat client. No wrapper CLI to install.

- Tool calls are drawn as what they act on rather than raw JSON, and you can approve one just once or "always" — including file edits, not only commands.
- A model's reasoning is shown alongside the tool calls it led to.
- New slash commands: `/model` to switch models, `/history` and `/output` to look back over a conversation and its tool output, `/status` to see the endpoint and key a chat is using, `/retry` to carry on a turn that failed or was interrupted, and `/forget` to withdraw a standing "always" permission.
- Cost and token usage are tracked per turn and shown on the status line, priced at whichever model actually answered.
- On Windows, panes running an API agent now run through a console twin of the app (`flockdeck-chat`), so the chat client always has a proper console to work in.

## agents.json: bring your own agents

Agents and the models they use are configured through an `agents.json` file, which can add agents of your own — a CLI or an API agent — or override entries in the built-in catalogue.

- An API agent's endpoint can now be viewed and changed from Settings, without hand-editing the file.
- Set a default agent and model for a whole project from the agent picker, and undo the change from the same place.

## Fan-out and worktrees

- Fan-out, which turns a plan into several agents each working in its own git worktree, now reads a plan written as numbered headings just as readily as a bulleted list.
- Folder trust is only asked for in a fan-out for the agents that actually ask about it.
- Flockdeck now asks before removing a worktree an agent is still working in, and refuses outright once a pane is running there.
- Broadcast now says clearly what it does and who it currently reaches, rather than describing itself as mirroring typing.

## Panes, tabs and the terminal

A long list of everyday interface improvements landed in this release:

- Search a terminal's contents as you type; choose the terminal's font, and have its size remembered between runs; turn off cursor blinking for reduced motion.
- Zoom a pane by double-clicking its header, with a clear sign when a zoomed pane is hiding something.
- Rename a tab from the command palette; close one with the middle mouse button; scroll a crowded tab strip with the mouse wheel.
- Recall earlier prompts in the prompt bar with the up and down arrows.
- Desktop notifications can be turned off from the window.

## Self-updates

- A staged update is now checked more carefully before it's applied — never installed over a build it wouldn't actually move forward from — and a release that's since been withdrawn is discarded rather than installed later.
- Update checks can be turned off entirely from Settings.
- Hitting GitHub's rate limit is now explained in plain terms, including when it lifts, instead of showing a bare error.

## Help and the flockdeck.ai website

- The in-app help now has a page listing every setting and how to change it, working search, and real links between related pages.
- The public website's install instructions are laid out as a proper keyboard-usable tab list, with an expanded FAQ and an accessible diagram of how the relay works.

---

This release also carries a large batch of hardening across git integration, session handling, preferences storage, project and workspace logic, the background server, and the web UI, following a set of internal audits of each subsystem. Individually these fixes aren't things you'd notice; together they mean fewer edge-case crashes and more accurate status throughout the app.
