# Flockdeck v0.3.34

## Windows opens its own window again
The fix that got the self-hosted Docker image building again (v0.3.32)
excluded Windows from the same code by mistake: the last two releases
(v0.3.32 and v0.3.33) silently fell back to opening Flockdeck in your
default browser instead of its own window, with a message about having
"no cgo" that made no sense on an ordinary Windows install. Windows never
needed cgo for this at all. Fixed, and covered by a test now, so a
build-tag mistake here fails a test instead of shipping quietly again.

## A data race fixed in the workspace's control connections
Closing a workspace didn't wait for every control connection's own
background goroutines to finish, only for the workspace's own loop to
return — a purely internal race that only ever showed up as flaky,
unrelated-looking test failures under `-race`, never in ordinary use.
