# Flockdeck v0.3.26

The biggest release in a while - a native window, a properly self-hosted
service mode, and a lot of everyday friction sanded off.

## A native window
Flockdeck no longer spawns a browser to show itself. The window is native
(Wails), starts faster, and the installer on Windows is a proper NSIS
package.

## Self-hosted, headless
`flockdeck -no-window` now runs fully unattended: every launch setting
(which folder, which agent starts first, every toggle) can be set entirely
through `FLOCKDECK_*` environment variables, so a provisioning script can
bring a machine online with no interactive step. A hardened Docker image
and a Helm chart are also available, for running Flockdeck as a service on
your own infrastructure.

## Terminal traffic is end-to-end encrypted
Remote access through the relay now end-to-end encrypts your terminal's
keystrokes and output, using keys the relay hands out but never holds - it
carries that traffic without being able to read it, even a relay you run
yourself. A pane's spend and usage state isn't covered yet, and it doesn't
yet defend against a relay that's been actively compromised at pairing.

## One project, several repos
A project can now group more than one repository: agents in sibling repos
see each other, and the switcher shows one entry instead of several
unrelated-looking ones.

## Managing projects
Projects can be renamed, removed, reordered and archived, with settings
per project, from the same place you already open and switch between them.

## A calmer app
Agents that need you at the same time now surface as one grouped prompt
instead of several separate interruptions. Finishing a batch of fanned-out
work produces a single readable summary. Switching projects no longer
waits on a disk write.

## Cost-aware model routing
A new Strategy setting lets fanned-out and helper work automatically drop
to the cheapest model likely to still do the job, with a dashboard showing
where that guess gets overridden.

## Customisation
Dark, Light or Follow-system theming with a proper light palette, a small
set of accent colours, a resizable sidebar, and a full keybinding remapper
with conflict detection and reset.

## The sidebar rail
The rail can now be widened into a panel and resized, VS Code-style, and
shows a badge when an agent waiting elsewhere needs you.

## GitHub, built in
A GitHub panel in the app itself shows pull requests, issues and CI status,
and lets you sign in with the `gh` CLI without leaving Flockdeck.

## Rollback and recall
`flockdeck update -version=X` installs a specific earlier version by name,
and the app now checks a signed list of versions that have been withdrawn
and warns you if you're running one.

## Automated PR review
Public repositories now get an automated code review on every pull
request, produced by a process that never exposes write access or a
review key to the code being reviewed.

## Release notes
This file, and the releases before it, are now backfilled and rendered
properly inside the app itself - the gap this note is closing shows why
that's worth doing for every release, not just the ones someone remembers.
