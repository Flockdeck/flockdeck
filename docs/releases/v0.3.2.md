# Flockdeck v0.3.2

## Settings, layouts and stored data
- Settings are no longer overwritten with a blank file if the previous settings failed to load.
- A saved pane layout is no longer discarded just because it couldn't be read when Flockdeck started.
- A damaged "recent projects" list no longer blocks new entries from being saved.
- Backup copies kept alongside your settings and layout files are no longer immediately overwritten by the next save.
- Deleting a stored API key now works reliably, fixing a case where it could appear to remain after being cleared.
- On Windows, saving and reading API keys in `keys.json` no longer fails when another process briefly holds the file open.

## Git and the Conversations dialog
- A rebase started from a detached HEAD still shows as in progress in the git pane.
- Conversations are now listed per project rather than mixed together.
- The Conversations dialog now renders reliably in the web UI.
- A modified file literally named `push` is no longer mistaken for the Push button.

## Remote access and installation
- Device names containing a backslash or `!` are now quoted correctly in the pairing command you copy.
- The install script now copes with a `HOME` or `PATH` entry that ends in a trailing slash.

## Faster, more reliable update checks
Flockdeck now checks for new releases against a copy of the update manifest cached for at most a minute, rather than up to five, and the self-update process no longer clears its working directory while a download could still be in progress.
