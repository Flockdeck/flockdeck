# Flockdeck v0.5.1

This release fixes Windows Security blocking the v0.5.0 download on Windows.

## What to do

If you are on Windows and the v0.5.0 update was blocked or quarantined by Windows Security, install v0.5.1. The in-app update will pick it up on its own, or you can run the installer from the release page. If you already allowed or restored v0.5.0, you do not need to do anything.

macOS and Linux were not affected. Apart from this fix, v0.5.1 has the same changes as v0.5.0, so see the v0.5.0 notes.

## What happened

Windows Defender flagged the v0.5.0 Windows binaries, `flockdeck.exe` and `flockdeck-chat.exe`, as `Trojan:Win32/LummaStealer.DO!MTB`. This was a false positive from machine-learning detection. It was triggered by readable lists of credential and browser file names in the code that keeps those files out of agent reach. Machines with Defender on could not install or update to v0.5.0.

Those names are now stored as hashes, so they no longer appear as plain text in the binary. Behaviour is unchanged.

## If Windows Security still flags it

Defender detections of this kind are heuristic, and one may still occur on some machines. If it does, you can report the file to Microsoft as a false positive on the Security Intelligence submission page, or restore it from Protection history in Windows Security.
