# Flockdeck v0.3.38

## Remote's full interface is now end-to-end encrypted, closing out the fix from v0.3.37
v0.3.37 stopped a stuck pane from spinning forever when a device had
registered an end-to-end key, but the interface had no WebCrypto client of
its own yet, so the handshake it needed still had nothing to complete
against. It does now: a browser reached through Remote's per-desktop full
interface makes and registers its own identity, and every pane's terminal
is end-to-end encrypted the same way flockdeck-remote's own app already is
— readable only by that browser and this desktop, never by the relay
carrying it in between, shared or self-hosted alike.
