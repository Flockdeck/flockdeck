# Flockdeck v0.3.8

## A live chat view on your phone
When you're paired with a device over remote access, opening a Claude Code pane on your phone now shows its conversation live, laid out as a chat rather than as a raw terminal.

## Fresh installs land on the latest release
A new install now starts on the newest available release rather than whichever version the installer happened to be built for, so you don't land on a stale build. Installs that already have automatic updates turned off keep that setting as it was.

## Terms and FAQ updated
The terms and FAQ no longer promise that the shared relay (used for remote access) will stay free forever, while continuing to make clear that the Flockdeck desktop app itself remains free and open source.
