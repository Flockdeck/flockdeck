# Flockdeck v0.2.10

## A left-hand rail, and a proper Settings dialog
Projects and tools now live in a rail down the left of the window, with tabs staying in the top bar where they've always been. Settings has moved out into its own dialog, reachable from the rail, the command palette, or Ctrl+, and on a narrow window the section you're in stays in view as you scroll.

## Worktrees and fan-outs say more about what's happening
- The worktrees view now flags any checkout whose folder has been deleted outside Flockdeck, and offers only Prune for it, rather than actions that would just fail.
- A fan-out shows which agents it started, so you can see at a glance what's running without hunting through tabs.

## Multi-line prompts and tab titles that remember themselves
- The prompt bar now accepts several lines - press Shift+Enter for a new line instead of sending early - and the whole prompt still reaches the agent as a single message.
- Renaming a tab keeps its automatic title in reserve: the rename dialog offers to hand it back, and clearing the name by hand reverts to it automatically.

## Remote access and agent endpoints
- This machine, and any device paired to your account, can now be renamed from the Remote access dialog in Settings, or from the command line with `flockdeck remote rename` (add `-device` to rename a device instead of this machine).
- The agent picker now saves and shows a custom API agent's endpoint address, and a bad address is reported back along with the address you should type instead.

## Signed updates, now served from Flockdeck's own servers
Flockdeck checks dl.flockdeck.ai for updates first, verifying each release's signature before installing it, with GitHub kept on as a mirror. Each release now publishes its own signed manifest, and the install scripts (install.sh and install.ps1) were hardened to match.

## Licensing, privacy and the relay
- The desktop app is open source under the MIT licence; the relay service and its client are not. Settings now says so plainly, with links to the privacy policy, terms and the full text of every third-party licence, shown beneath your plan.
- Flockdeck no longer offers to run a private relay of your own. Settings instead announces a self-hosted relay for companies, coming as part of Enterprise, with no pricing set yet.

## Also in this release
Pane headers now say clearly when a git status check has timed out, rather than showing counts that might be stale. The Start menu and the open-projects list can take you straight back to a project you already have open. Flockdeck also has a proper application icon on Windows. A number of smaller reliability fixes and general polish landed alongside all of the above.
