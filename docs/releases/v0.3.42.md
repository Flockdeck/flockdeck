# Flockdeck v0.3.42

## Project tiles show what each project's agents are doing
The rail down the left of the window used to badge a project's tile only
when an agent in it was waiting on you. It now also says when agents are at
work, so you can tell which of the projects you are not looking at is still
busy.

- An **amber** badge means an agent in that project is waiting on you (a
  blocked one counts as waiting, as in the top bar).
- A **pulsing green** badge means agents are working and none is waiting.
- No badge means every pane is idle, exited or not yet heard from, or the
  project has no panes. Amber wins when both amber and green are true.
- Colour is not the only signal. Widen the rail and the count is written
  beside the project's name: `▲ 2` for two waiting, `● 3` for three
  working. The tile's tooltip and screen-reader name say it in words.
- A window reached through the relay shows the same.

## Close finished panes leaves agents with background work alone
**Close finished panes** and `flockdeck close --finished` close every idle
agent, but an agent goes idle when its turn ends whatever it left running.
Closing one that had started a command with `run_in_background`, or a
background subagent, killed that work. Such an agent is now not counted as
finished and is left open, and `flockdeck close <pane-id>` treats it as
work in progress too. Exited panes are still closed, whatever they left
running.

- Flockdeck learns of background work from the agent's hooks. A background
  command counts from the moment it starts; a subagent from its start to its
  stop. A Claude Code too old to report subagents is only seen to have
  background commands.
- **Limitation:** a background command that ends on its own is not seen to
  end, so it keeps counting until the agent stops it, the conversation is
  cleared, or you close the pane by hand or with `flockdeck close --force`.
  A pane is kept rather than closed by mistake, which is the safe way to be
  wrong.
- Compacting or resuming a conversation keeps what was running; clearing it
  forgets it.
