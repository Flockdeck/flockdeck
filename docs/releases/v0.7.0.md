# Flockdeck v0.7.0

This release adds roles and a Team panel to the window, tidies the window's buttons and names, and removes common secrets from the text sent for Jev status detection and routing.

## Roles in the window

The agent picker has a Role control. Choosing a role asks for a task and starts the agent with that role's agent and model, unless you pick an agent and model from the list yourself. The worktree box is ticked for roles that expect their own branch.

- A role tag shows in the pane header, the Agents overview and Pane info.
- "Start a team" in the command palette starts a manager agent from a goal you type, and the manager starts the rest.
- Settings > Agents & models lists the roles.

## Team panel

Open the Team panel with `Ctrl+Shift+M`, the Team button in the rail, or "Team..." in the Agents overview. It has three tabs and updates live.

- Roster lists the agent panes of the project with role, agent, model, status, branch and current task. Click a row to go to the pane.
- Tasks is the task board. Open a task to read its notes, add a note, assign it, set its branch or move it to another state. You can also add tasks.
- Messages shows the project's messages, which you can filter by pane or role. Send one as "you" and the pane or role you pick is told.

## Tidier window

- "Resume" is now the one name for reopening a past conversation.
- "Auto-approve read-only" is the new name for "Auto-review". Searching Settings for the old name still finds it.
- The rail has 12 buttons instead of 14. API keys, Remote and GitHub are in the command palette and Settings.
- The Remote status shows on the Settings button: a filled circle when connected, a hollow one while connecting, and an amber triangle when it needs you.
- Settings has an "About & updates" section for the version, updates and legal links. "Account & plan" keeps the plan cards.
- The TypeSafe key is set in Settings > API keys.
- Terminal font and scrollback are set in Settings, which has an "Other scrollback" field for any value from 1,000 to 200,000.

## Window style

Header, tab and button sizes are consistent, and buttons, tabs and list rows react when pressed. Switches and colour chips are easier to hit. Contrast is better in increased-contrast mode and for dim text on tinted pane headers. The pane lock shows as an icon.

## Jev

When Jev status detection or routing is on, common secrets are removed by pattern before text is sent: API keys, bearer tokens, passwords in URLs, private key blocks, values with secret-like names, and paths to `.env` and key files.

## Other changes

- Agents get a shorter startup briefing.
