# Flockdeck v0.3.43

## Pane status stays right when hook events arrive late, stray or not at all
A pane's status is now driven by the turn it is in, not by each event on its
own, so a late, duplicated or missing hook event can no longer strand a pane
on the wrong status.

- A tool result that belongs to a turn that has already finished is dropped
  rather than turning the pane back to working.
- A background subagent's tool calls no longer make an idle pane flicker.
- A pane whose prompt was never reported, but which keeps drawing after Enter,
  is shown as working, and returns to idle when it goes quiet.
- A manual `/compact` shows working, then idle when it ends.
- An older Claude Code's bare idle nudge no longer makes an idle pane look
  like it wants attention.
- Flockdeck now learns when background work ends, so **Close finished panes**
  and `flockdeck close --finished` stop treating a finished background command
  as work in progress. Background work is also shown in the window.
- Every status case is written down in `docs/status-matrix.md` and tested.

## A pane that exited with an error looks different from one that finished
A pane whose process exited with a non-zero code, or was killed, is shown as
failed, with the exit code, and is left open for you to read. A clean exit is
muted instead of red, and is still closed by **Close finished panes**.

## Git windows offer the repositories inside a folder
When the folder a Worktrees or Changes window looks at is not itself a git
repository but holds some, the window lists them. Pick one and the window
works on it. Before, it only said the folder was not a repository.

## Every built-in CLI agent is briefed
Codex, Gemini CLI, opencode and Cursor Agent are now given Flockdeck's
briefing, as Claude Code is. Aider is briefed only when its pane has a task,
because its one-shot `--message` would otherwise answer the briefing and exit.

## Fixes
- The hint bar no longer cycles a status-gated tip while a status flaps slowly.
- Remote access: a relay that has gone quiet is reported as not answering,
  and a relay that closed the tunnel as revoked or replaced is no longer
  dialled again. A close by this end is no longer mistaken for the tunnel
  failing.
- `flockdeck help` is documented on the command-line page.
