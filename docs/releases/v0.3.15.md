# Flockdeck v0.3.15

## Remote access
Documentation now makes clear that opening an agent from a paired phone puts you straight into a chat-style view of its conversation, and that the relay carrying that connection doesn't store any of it.

## Performance
A pane nobody currently has open no longer keeps its whole conversation resident in memory - it's tailed instead, which lightens the load in workspaces running a lot of agents at once.
