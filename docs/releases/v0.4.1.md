# Flockdeck v0.4.1

This release makes the app and the website say what the live relay does, and hides three buttons that did nothing where they were shown.

## Changes

- The privacy page and the terms now state the relay's retention rules: an account is kept while it is paid for or has been used in the last 90 days, and otherwise it is deleted with its desktops and devices, without a warning email.
- Use means a desktop connecting, a paired device's use, a registration, a join, or removing a desktop.
- A desktop that enrolled and never connected is dropped after 7 days. The 30-day removal of quiet desktops is gone, and removing a desktop never deletes the account.
- The privacy page has a new section on joining an account by confirming its email address, with the notice email and the push notice to paired devices.
- The auto-review switch is no longer shown on shell panes, and the server refuses it there. A shell makes no tool calls to review, so the switch did nothing.
- Export and Show in folder are no longer shown in a window reached through the relay. The server already refused them there, with a notice.
- The Help page for Flockdeck Remote carries the same retention wording as the privacy page.

## Smaller changes

- The unused window-link redirect file bookkeeping is gone. The desktop window loads its link directly, as before.
