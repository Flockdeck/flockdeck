# Flockdeck v0.3.3

A stabilisation release: it firms up the fan-out, remote access and chat-client work from recent versions, and adds a substantial accessibility pass.

## Accessibility
- Screen readers now read out what each agent writes, and announce which agent is waiting for input rather than just a count of them.
- You can reach and scroll the diff and release-notes views from the keyboard, move focus out of a terminal pane with F6, and an exited pane's alert takes you straight to its Restart button.
- Text fields now have a visible edge, pane header text meets proper contrast (4.5:1) when a pane is waiting or has exited, and the focus ring on tabs is no longer clipped by the tab strip.
- The prompt and find bars now fit a narrow window, and a desktop notification is cleared once you've answered it.

## Fan-out reliability
- Plans are parsed more reliably: a reply that breaks off mid-code-block, or one that mentions the CLI's own status line, no longer loses its plan or tasks; a long step is kept whole, and a step that genuinely had to be cut now says so; a plan grouped under labels shows its steps under each label.
- Fan-out rows that share the same task now show that they share it, instead of looking independent.
- If starting an agent in a fan-out fails, only the worktree and branch that run created are cleaned up - runs from other agents are left alone - and the fan-out dialog now submits only the answer it actually asked for.

## Chat client and agent connections
- An OpenAI-compatible endpoint with its own path is now treated as the API root rather than having a path appended to it, and a redirect to a different address is no longer sent your API key. Calls made through a gateway are never sent your underlying provider key either, and are counted in tokens rather than priced.
- A stream that breaks off partway through still reports what it spent, and a request an API asks you to wait on is left for you to retry with `/retry` rather than retried silently.
- Picking an agent without choosing a model now shows that agent's own default model, and hiding your default agent falls back to opening the first agent on offer instead of nothing.

## Update and remote-access safety
- A self-update fetched from GitHub now also needs the release key's own signature, a download is cut off if it runs past its published size, and Flockdeck will never move an install back to an older release.
- Changing remote access settings or API keys, and restarting Flockdeck, can now only be done at the desk - a window opened from a paired device is refused both.

## Also in this release
Git push, pull and fetch no longer hang waiting for ssh to prompt on the terminal. Closing a pane now stops everything its process started, while any separate windowed program it launched is left running. The review view keeps bracketed characters in file names, tells you how many files it's left out of a long diff, and refuses to commit if the underlying tree has moved since you looked at it; diff hunks now draw `---`/`+++` lines correctly instead of as changes. Command-line tools no longer touch `.git` under "always" edit mode, and a glob pattern with many `**` segments can no longer run unbounded. A large number of smaller fixes and polish landed alongside these.
