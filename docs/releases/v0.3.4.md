# Flockdeck v0.3.4

A large reliability and hardening release, covering agent connections, git and worktrees, the sandbox agents run commands in, and the web interface.

## Steadier connections to your agents
- Errors are now reported consistently across every provider - OpenAI, Gemini, Anthropic and gateways alike: a dropped HTTP/2 stream, a broken mid-stream connection, an unreachable proxy or an untrusted certificate are all explained in plain words instead of surfacing as a raw failure. A stream chunk that can't be read is reported rather than silently skipped.
- Refusals from the model are now worded the same way regardless of provider, and are no longer offered a `/retry` that wouldn't help.
- A pane waiting on a missing API key returns to its normal prompt as soon as you supply one, and a permission prompt you refuse from the keyboard returns its pane to idle properly.
- Vendor API keys are never sent to an agent that's routed through a gateway, whether you started that chat by hand or Flockdeck started it for you, and every place Flockdeck looks up a key now checks in the same order.
- The cost figure in a pane header explains itself when a gateway means nothing can be priced, and no longer double-counts a reading an idle pane sends again.

## Git and worktrees
- Creating a worktree now gets as long to check out as a push does, and a checkout Flockdeck gives up on is fully terminated - along with everything it started - rather than left to finish in the background.
- SSH push, pull and fetch failures now explain how to get past them instead of just failing.
- A merge conflict with no markers left to resolve is refused rather than committed as-is, and filenames that aren't valid UTF-8 no longer block a commit.
- Commits now take exactly the files you reviewed, no more and no less; a rebase or a detached HEAD is shown as such, with no Push offered; and diffs, commit-message drafts and the review panel now always match the checkout you're actually looking at, even if you switch panes quickly. A branch that's diverged from its remote is no longer offered a Pull that would only fail.
- Changes inside a submodule are shown in the review panel rather than cluttering the pane header, and the worktree panel now loads a large project's worktrees eight at a time instead of stalling on all of them at once.

## Agent command safety
Flockdeck sandboxes the shell commands your agents run, and this release closes several ways round it: more spellings and invocations of a shell are caught (including `cmd.exe.` and case-folding tricks), and a path built from another name for the pane's own directory - such as a drive letter alias - is now correctly recognised as inside it rather than treated as external. Git commands Flockdeck runs on your behalf no longer execute a repository-configured fsmonitor command. A command stopped with Ctrl+C now says it was interrupted by you, rather than reporting a generic failure.

## Web interface: input, clipboard and touch
- On a Mac, Option plus a digit types the character while Cmd still switches tabs, and Ctrl+0 resets the font size correctly on AZERTY keyboards.
- Ctrl+C and Ctrl+V now copy and paste the Windows Terminal way, and dragging a finger scrolls a pane - including apps running on the alternate screen, such as vim or less.
- A paste over a mebibyte is sent to the agent in manageable chunks, and pasted text can no longer break out of paste mode to inject extra keystrokes.
- Window shortcuts no longer fire behind an open dialog, F6 and Shift+F6 always leave the prompt bar for the rest of the window, and high-contrast mode again shows what's selected and what's toggled on.
- Settings left open now survive a reconnect, a link a terminal program prints opens in a window of its own, and only panes actually visible on screen render with WebGL - which should help with GPU load and battery life when a lot of panes are open.

## Remote access and privacy
The relay does not record, store or log traffic passing through it, keeps no details of connecting browsers, and drops desktops that never actually connect. Join codes for another desktop can only be created at the desk, never from a paired device. A remote pane catching up after a reconnect now receives its backlog in properly sized frames and isn't disconnected for being slow to catch up, and a relay that revokes this machine is noticed even while Flockdeck is still shutting its connection down. Internal error messages no longer include Flockdeck's own authentication token.

## Self-update
A download that fails to stage leaves the previously staged update in place rather than losing it. Candidates from GitHub that aren't genuine releases are refused, the same as they already were from dl.flockdeck.ai, and installing an update now waits for antivirus or other scanners to release their hold on the file before swapping it in.

## Also in this release
Closing a pane now reliably ends the shell jobs and child processes it started - including on Windows, where a reused process ID used to fool the cleanup - while leaving any separate windowed program it launched running. Local data files are handled more carefully: a damaged file is set aside and reported rather than silently discarded, and preferences written by a newer build of Flockdeck are no longer overwritten by an older one opening the same file. The conversation history list no longer mixes in a neighbouring project's chats, correctly shows conversations you've renamed with `/rename`, and loads faster by caching folders it has already read. `install.sh` and `install.ps1` fail faster against a stalled or unreachable site and quote paths correctly. The default browser is waited for rather than left running in the background when Flockdeck opens a link, and Flatpak and snap browsers now open the application window correctly. A long tail of smaller server- and interface-side fixes landed too.
