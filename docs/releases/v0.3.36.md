# Flockdeck v0.3.36

## Turn a spec into a plan, and the plan into agents
Write a feature in your own words and have an agent draft an
implementation plan from it, saved as a per-project checklist you can
edit and reorder. Start any step on its own, on demand — optionally in
its own worktree, branched under the checklist's name — and its
completion is picked up automatically from how that pane finished,
with a manual override either way and the full history of every
attempt kept per step.

## A fixed dependency, and the self-hosted image's checks now run end to end
`golang.org/x/crypto` is bumped to close an authentication-bypass
vulnerability in its SSH package (CVE-2026-56854) — caught by the
self-hosted Docker image's own vulnerability scan, which, after the
last two releases got it building and its SBOM attaching again, now
runs its full pipeline — build, SBOM, scan, signing — without a step
left broken partway through.
