# Flockdeck v0.1.0

## Workspace: tabs, splits, and layouts
Every agent gets its own real terminal pane, arranged into tabs and splits you build by hand. Drag a pane out into a new tab, split it in any direction, resize dividers precisely (including from the keyboard), and move focus between panes with the arrow keys. Layouts save and restore automatically, divider positions and pane sizes included, so a workspace comes back exactly as you left it after a restart. You can have more than one project open at once, each keeping its own tabs and its own last-used tab, and reopening a project whose checkout path is spelled slightly differently no longer opens a second copy of it. A broadcast mode sends the same keystrokes to several panes at once, and can be switched off when you only want to talk to one agent.

## Any coding agent, your choice
Flockdeck isn't tied to one agent. Alongside Claude Code, it can run Codex, Gemini, Aider, opencode, Cursor's agent, or talk to a model API directly in its own chat pane, with API credentials resolved from your environment or a private store and never shown again. Pick the agent and model per pane, from the interface or the command line, and agents without their own hook support are briefed on the project and worktree they're in through their opening prompt instead.

## Fan-out: turn a plan into several agents
Point Flockdeck at a plan an agent has written - numbered, lettered, bulleted, written as checkboxes, or in a language other than English - and it turns each task into its own agent, each working in its own git worktree so they don't tread on one another. Worktrees are created together up front and siblings are kept out of each other's checkouts, and there's a cap on how many agents a single fan-out will start. If a task fails to start, or nothing in a plan looks like a task, Flockdeck says so in a summary rather than leaving you to work it out.

## Git, built in
A review panel shows staged and unstaged changes, diffs renames as renames rather than as wholesale rewrites, handles conflicts and submodules, and tells you when a diff has been cut off because it's too large to show in full. Status shows the current branch, including where a stopped rebase is heading back to. Push, pull, and fetch report what git actually said if they fail, and Flockdeck manages the git worktrees that fan-out and multi-checkout working rely on, including clearing out stale ones.

## History and agent status
Agent transcripts are kept and searchable across projects, including conversations that later moved into a worktree, so past sessions can be found and picked back up. Each pane shows a live status - idle, waiting on you, or busy - along with what it's costing the machine, and a bell notification reaches you even in a pane you haven't typed into yet.

## Keeping itself up to date
Flockdeck checks for and installs its own updates from signed releases, published for each supported platform, so a running install stays current without manual downloads.

## Command line
The `spawn` command starts a new pane from a script or from another agent, with flags for the agent, model, shell, and working directory - the same mechanism fan-out uses internally to bring sibling agents up.

## Interface polish and accessibility
Keyboard focus is always visible, including under Windows high contrast, and every icon-only button has an accessible name. Toasts and the disconnected screen are announced properly for screen readers, motion respects your system's reduced-motion setting, and the interface adapts at narrow window widths rather than clipping the tab bar or overflowing dialogs. A built-in help index documents every action and its keyboard shortcut, kept in step with the app itself.

## And everything else
A long tail of smaller fixes and refinements landed alongside all of the above - to layout arithmetic, terminal output handling, and project and session bookkeeping among other things - too many to list individually, but they add up to a noticeably steadier app.
