# Flockdeck v0.3.0

## Spend and limits, in the pane header
Every pane now shows what its agent has spent and how close it is to any usage limit, tracked live as the agent runs. This covers agents that report their own spend through hooks, and direct API chat panes, where every call's tokens and estimated cost are tracked directly, priced from a dated table covering every built-in model and its tier. The same figures reach paired devices too, in the web UI's pane headers.

## Your own status line, from Claude Code
A Claude Code pane can now run your own status line command through Flockdeck, with the bridge feeding it Claude Code's own limits so it keeps showing what it always has. The command starts with its window hidden, so it doesn't flash up on screen.

## Routing rules can choose a model for fan-out
Routing rules can now pre-set which model each row of a fan-out uses, picking one suited to the task instead of leaving every agent on the same default.
